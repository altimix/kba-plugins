# kba プラグイン(求人ボックス自動化)

求人ボックス(採用ボード)の運用を Claude から行うためのスキル群と、kba Remote MCP への接続設定を
1つにまとめたもの。

## 同梱物

| スキル | 担当 |
|---|---|
| `drafting-kbx-jobs` | 原稿を作り、レビューシートへ載せる |
| `revising-and-submitting-kbx-jobs` | シート上で直し、承認を経て本番へ入稿する |
| `preparing-kbx-photos` | 写真を用意し、求人ボックスで使える ID にする |
| `rotating-kbx-jobs` | 月次でグループごとに書き直して新着化する |
| `analyzing-kbx-performance` | 成果を分析し、次に直すことを優先度付きで出す |
| `operating-kbx-environment` | 状態確認、接続復旧、新規クライアントの立ち上げ |

接続設定は `.mcp.json`。エンドポイントは `https://mcp.kba.bazaarinc.dev/mcp`。

## 設計

**スキルは薄く保つ。** ここに書いてあるのは、意図とツールの対応、順序、守るべき約束だけ。
媒体仕様・運用ルール・チェック内容のように変わるものは**サーバから配信**される。

```
kba_get_skill_guidance({ topic: "generation" })   # 例: drafting-kbx-jobs
```

多くのスキルは作業前に、担当する topic の guidance をこれで取得する(topic の一覧は `topic: "index"`)。**プラグインを更新しなくてもサーバ側の更新が反映される**ので、
プラグイン自体の更新はまれ。

## 利用前提

- kba Remote MCP に接続していること。認証は接続時の OAuth
- 利用できるクライアントと操作範囲はアカウントごとに決まる
- claude.ai のサンドボックスから通信する場合、許可ドメインに `mcp.kba.bazaarinc.dev` を一度追加する

## 本番への書き込みについて

CSV の入稿と求人ボックスへの写真登録は、**人の承認を通してから**実行される。承認を省略する経路は無い。

権限や設定が足りずに止まった場合は、返ってきた理由がそのまま示される。設定の変更は運用者に依頼する。

## 秘密情報

**含まない。** 認証情報・トークン・Cookie はプラグインに焼かず、すべて接続時の OAuth と
サーバ側の設定で扱う。

## 配布

`altimix/kba-plugins` のマーケットプレイス経由。GitHub アカウントは不要で、Claude の
プラグイン画面からリポジトリを指定して同期する。

更新の告知があったら同期を1回押す。自動同期は使えない。
