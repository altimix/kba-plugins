# 有料レポートからの候補出し

キーワード・キャンペーン・求人レポートの**書き出し済みデータ**を読むときの手順。
この skill から求人ボックスのレポートを取得しない。利用者が渡した書き出しだけを扱う。

**出せるのは候補であって決定ではない。** 有料設定・原稿・入稿の姿勢・顧客への説明を変えうる出力は、
すべて人の確認を通す。

## 候補の種類

| 種類 | 内容 |
|---|---|
| 除外キーワード | 的外れ、または費用が無駄になっている検索語 |
| 強化キーワード | 応募につながっており、原稿・予算を寄せる価値がある検索語 |
| 予算の見直し | CPA / CVR の傾向が悪い、または良いキャンペーン・求人・クライアント |
| 原稿の書き直し | 原稿で直せる切り口。実際の修正は revising-and-submitting-kbx-jobs |
| 顧客向けコメント | 根拠と留保を添えた報告文の下書き |

## 添える根拠

分かる範囲で必ず添える。

- 期間、対象(クライアント / キャンペーン / 求人)、データの出所、鮮度
- 対象のキーワード・検索語
- 表示、クリック、応募、費用、CTR、CVR、CPC、CPA
- 採用数と採用単価(**確定している場合のみ**)
- 判断に使った比較対象(前期間 / 同一範囲内の相対)

## 判断の目安

**除外候補** — 費用やクリックがそれなりにあって応募がゼロ、職種が明らかに違う、地域が違う、
資格要件が合わない、雇用形態が違う、顧客が使わないと決めた表現。**分母が小さい場合は参考値**と明記する。

**強化候補** — 応募が出ている、または同じクライアント・キャンペーンの中で CVR / CPA が明確に良い。
**採用まで至ったかは、採用データが無い限り推測しない。**

**顧客向けコメント** — 事実と提案を混ぜない。「観測されたこと」「推定される原因」「次にやること」
「承認が要ること」が読み分けられる形にする。

**採用単価が確定しているならそれを優先する。** 無い場合は「CPA は応募単価であって採用単価ではない」と
明記する。

## 出す形

```json
{
  "candidateType": "exclude_keyword",
  "scope": "クライアント / キャンペーン / 求人 / 期間",
  "keyword": "例",
  "evidence": {
    "impressions": 0,
    "clicks": 0,
    "applications": 0,
    "cost": 0,
    "ctr": null,
    "cvr": null,
    "cpc": null,
    "cpa": null
  },
  "reason": "根拠に基づく診断を運用者の言葉で",
  "confidence": "high | medium | reference-only",
  "requiresHumanConfirmation": true,
  "requiresCustomerConfirmation": true
}
```

## 守ること

- 候補を**すでに適用済みの設定であるかのように示さない**
- この経路から除外語・強化語・キャンペーン設定・原稿・CSV 入稿を**書き込まない**
- 分析結果を理由に、中継できる CSV 入稿を止めない。所見は警告・推奨として示し、
  受理の判断は求人ボックス側の応答に委ねる
- 生成結果のスナップショットを編集の正本として扱わない
